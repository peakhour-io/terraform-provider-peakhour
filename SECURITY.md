# Security Policy

## Supported versions

Until the provider reaches version 1.0, security fixes are made on the latest
released version only.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability or include API
keys, Terraform state, customer domains, or other sensitive data in an issue.

Report security concerns privately through
[Peakhour Support](https://www.peakhour.io/support). Include the affected
provider version, a description of the impact, and reproduction details that do
not contain production credentials. We will acknowledge the report and arrange
a secure channel for any sensitive supporting material.
